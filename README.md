🚗 Proyectos destacados

Calculadora de ventas de vehículos

Mi primer proyecto personal, creado para aplicar los conocimientos de programación a un caso práctico del sector de la automoción.

La versión inicial permite calcular el precio final de venta de determinados vehículos tras aplicar un descuento comercial, así como el beneficio de cada operación para el concesionario.

El objetivo es desarrollar progresivamente nuevas funcionalidades hasta convertirlo en una aplicación más completa.

🌱 Mi filosofía de aprendizaje

Creo que la mejor manera de aprender a programar es combinar la teoría con la práctica, experimentar, equivocarse y buscar soluciones.

Por eso, este GitHub no pretende mostrar únicamente proyectos terminados, sino también el proceso que hay detrás de cada uno de ellos: desde los primeros ejercicios hasta aplicaciones cada vez más completas.

Mi objetivo es construir una base sólida como desarrollador, mantener una mentalidad de aprendizaje continuo y crear proyectos que aporten valor.
